# Запрещённые строки для публичного шаблона — ПРИМЕР формата.
#
# Настоящий список лежит ВНЕ репозитория:
#   ~/.harness/<имя-каталога-репо>-private-terms.txt
# путь переопределяется переменной HARNESS_PRIVATE_TERMS.
#
# Почему снаружи: проверка, запрещающая строку, обязана эту строку содержать. Трекаемый
# список сам стал бы утечкой — публичный репозиторий получил бы аккуратный перечень
# внутренних имён в одном файле.
#
# Читает его `scripts/check-docs-reality.sh` (проверка 22): каждая строка ищется по всем
# трекаемым файлам через `git ls-files`. Найдено → красное, в вывод идут только имена
# файлов, сам термин никогда не печатается.
#
# Файла нет → проверка ПРОПУСКАЕТСЯ вслух. «Список не найден» и «утечек нет» — разные ответы,
# и второй нельзя выдавать за первый.
#
# Формат: одна строка на термин, `#` — комментарий, пустые строки игнорируются.
# Регистр не важен (сравнение через `grep -i`), регексов нет (`grep -F`).

# Денилист чистоты CORE: токены, привязанные к конкретному стеку.
#
# Зачем файлом, а не внутри скрипта. Число помеченных строк — функция от денилиста, а не
# измерение: два прогона по списку «из головы» дали 31 и 15. Пока список не зафиксирован,
# замер не воспроизводится, и говорить «поднято N строк» бессмысленно.
#
# Основание критерия — ESLint «Library agnostic»: правило опирается на среду выполнения,
# а не на конкретную библиотеку. Правило, которое нельзя сформулировать без `vitest`,
# для .NET-инстанса и не правило.
#
# Формат: один токен на строку, регистронезависимо, как фиксированная подстрока (не regex).
# Пустые строки и строки с `#` игнорируются.
#
# Escape-hatch: `<!-- core-ok: причина -->` в той же строке или в предыдущей. Причина
# обязательна — пустой core-ok скрипт не принимает, иначе метка станет способом не думать.

## Verification (AC)

**Поведенческий критерий пишется с ID.** Без ID нельзя проверить, что у критерия есть тест:
`scripts/check-ac-refs.sh` ищет ID в тестах грепом — по тексту критерия искать нечего.
ID ставится в тест: в имя (`it('AC-001: пустой список даёт заглушку')`) или комментарием рядом.

- [ ] **AC-001** — <проверяемый критерий поведения>
- [ ] **AC-002** — <ещё один>

Префикс `AC` годится, пока спека одна. Спек несколько → префикс кода фичи (`WF2V-001`),
иначе номера столкнутся между спеками; тогда поправь `AC_ID_RE` в `.harness.conf`.

**Без ID — то, что закрывает сам гейт, а не отдельный тест:**

- [ ] gate зелёный (проверки без тестов) + тесты зелёные

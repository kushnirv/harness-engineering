# Context Hygiene — гигиена контекстного окна

Загружается всегда (нет `paths`). Стек-независимо. CORE-слой.

- **Источник истины — файлы, не история чата.** План, задачи, состояние держи в файлах
  (план/overview/доки); читай их, не полагайся на прокрутку истории. История сжимается — файл нет.
- **Вывод хука ушёл в файл — прочитай файл, preview за контекст не считай.** Лимит — 10 000
  символов на строку вывода хука (`stdout`, `additionalContext`, `systemMessage` одинаково);
  сверх него в контекст идёт preview ~2KB, остальное лежит по пути из `persisted-output`.
  Обрезается хвост, а выглядит это как нормально загруженный контекст.
  Открой файл целиком до первого действия. Проверять причину, а не дисциплину: вывод хука,
  который перестал влезать, чинится в самом хуке (Gotcha 53).
  <!-- стоило: DoR-пакет по Workflows собран второй раз с нуля, 27.07 -->

- **`/compact` проактивно, на границе задачи.** Длинная сессия вытесняет правила и контекст
  (context rot). Сжимай до того, как поплыло, не когда уже потерял нить. **В многослойной сборке
  (порт → хук → UI → …) — на границе КАЖДОГО слоя**, не копить >150k: длинный контекст дорог даже
  кэшированный (наблюдалось «49% usage at >150k», 6h-сессия). Агент напоминает одной строкой,
  зовёт пользователь. <!-- стоило: рост контекста через 5 слоёв без промежуточного compact -->

- **После тяжёлой MCP-фазы (Figma, chrome-devtools, скриншоты, большие дампы) — предложить `/compact`.**
  Дампы MCP-тулов раздувают окно и роняют скорость генерации КАЖДОГО следующего токена
  (наблюдалось 16–26 tok/s против ~70 номинала). Порядок: выжимку фактов сохранить в файл
  (спека/док) ДО compact — потом сжимать. <!-- стоило: зависания Write по 5-10 мин, 08.07 -->
- **JIT-загрузка, не всё впрок.** Тяжёлые доки читать по требованию (Read), не тащить в старт-контекст.
  `@import` НЕ лениво — грузит на старте, для JIT не годится. Always-loaded держи тонким (см. корневой CLAUDE.md).
- **Подсвечивай деградацию, не действуй по памяти.** Подозрение, что правило/факт выпали из окна —
  скажи и перечитай с диска.
